#  Pranjal Cake Shop

Hi! 
This is my mini project **Pranjal Cake Shop**, a simple front-end website I built to practice my web development skills using HTML, CSS, and JavaScript.
The idea behind this project is to create a basic online cake shop where users can explore different cakes and interact with the website in a clean and simple way.

# About the Project

While learning web development, I wanted to build something practical instead of just theory.
So I created this cake shop website where I focused on designing the layout, adding styles, and making it responsive.
This project helped me understand how real websites are structured and designed.

# What I Built

* A homepage with a clean and attractive design
* A section to display different cakes
* A login/signup form
* Basic responsiveness (works on mobile and desktop)
* Simple interactive elements using JavaScript

# Technologies I Used

* HTML → to structure the website
* CSS → to design and style the pages
* JavaScript → to add basic interactivity
* Font Awesome → for icons

# How to Run This Project

1. Download or clone this repository
2. Open the project folder
3. Run `index.html` in any browser
